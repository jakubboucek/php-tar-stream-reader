# PAX fixtures

These archives are generated by GNU tar 1.35, not by the PHP parser under test. `generate.py` verifies names, sizes and file bytes with Python's independent `tarfile` implementation before writing fixtures and `manifest.json`.

Run `python3 tests/assets/pax/generate.py gtar` with Python 3 and GNU tar installed. Alternatively, pass a Docker command:

```sh
python3 tests/assets/pax/generate.py docker run --rm --network none \
    -v /tmp:/tmp jakubboucek/lamp-devstack-php:8.4-cli tar
```

The generator only writes these fixtures and uses a temporary input directory. Tests consume committed archives and do not require Python, tar or Docker inside their PHP environment.

- `local-path`: a long UTF-8 name containing a newline, between two ordinary files.
- `local-size`: explicit local size records on two three-byte files.
- `global-comment`: an ignored global record followed by ordinary files.
- `global-size`, `global-path`: valid global overrides that the reader deliberately rejects.
- `padding-*`: extension payloads exactly 511, 512, 513 and 1024 bytes long, checked independently during generation.

A fixed fractional mtime forces GNU tar to emit local extended headers even for short filenames. Forced local keywords alone may not cause GNU tar to create a header when all native metadata fits USTAR. The boundary fixtures account for both the mtime and comment records.

Integration tests derive invalid/truncated archives from these files and change selected physical sizes with recalculated checksums. The size override test deliberately makes the physical USTAR size disagree with the valid PAX size. No test needs to transfer multi-gigabyte content.
